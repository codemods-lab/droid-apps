# DroidApps

Signed release APKs for [DroidApps Store](https://github.com/codemods-lab/droidapps-store). This repo holds releases only; there is no source code here.

Each release is tagged `<app-id>-vX.Y.Z` (for example `spendlens-v1.0.0`) and is created by that app's CI. Don't create releases here by hand.
